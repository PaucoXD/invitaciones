Enlaces personalizados para invitados

Cada invitado verá su nombre en el sobre, cuántos lugares tiene y (si contrataron el paquete) su mesa. La lista se edita en la sección “Invitados”. Primero publica la invitación con 🌐 Publicar: su dirección aparece aquí sola.

Invitación en PDF

Para quienes prefieren algo sencillo: se abre en cualquier celular, se manda por WhatsApp y se puede imprimir (tamaño A5). Tiene el mismo diseño, y los botones de mapa y WhatsApp se pueden tocar.

Si la escribes, el PDF incluye un código QR que abre la invitación digital de esa familia.

🌐 Publicar invitación

Sube la invitación a tu sitio. En 1 o 2 minutos queda en línea con su enlace, lista para mandar. Si la vuelves a publicar con el mismo nombre, el enlace no cambia y tus clientes ven los cambios.

🔑 Llave de GitHub
  1. Abre github.com → Fine-grained token (con tu sesión de GitHub).
  2. Nombre: publicar invitaciones. Expiración: 1 año.
  3. Repository access → Only select repositories → .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, cópialo y pégalo aquí.

La llave se guarda solo en este navegador y solo sirve para tu repositorio de invitaciones.
