# Invitaciones digitales

Invitación de boda de ejemplo (ficticia): **Valeria & Santiago**, en `index.html`.

## Personalizar por invitado
Agrega parámetros al enlace para que cada invitado vea su nombre y sus lugares reservados:

```
index.html?invitado=Familia%20López&pases=4
```

## Cambiar los datos
- Textos (nombres, padres, lugares, horarios): edítalos directamente en `index.html`.
- Fecha, número de WhatsApp para confirmaciones y nombres de la pareja: objeto `CONFIG` al final del archivo.
- Colores: variables CSS en `:root`.

Se puede publicar gratis con GitHub Pages (Settings → Pages → rama principal).
